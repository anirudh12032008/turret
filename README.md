# turret
this is a semi automatic nerf dart shooting turret made with 2 dc motors and 1 n20 motor.
the turret is controlled by an esp32 mcu with a drv8833 motor driver with 3d printable design


## why it exists
i created this as a fun project to shoot my frirnds and simultaneously learn more about hardware.
the entire project was made with breadboard not th regular PCNs
this project uses C++ as the programming language


## how to build/use
3d print the parts in the repo and assemble it along with the electronics available from the BOM
